# 🚀 Автоматическое сохранение версий и отправка в GitHub (VIBES)

Данный гайд объясняет, как настроить твой GitHub репозиторий один раз, после чего агент сможет **автоматически по твоей команде** инкрементировать версии, делать коммиты и пушить код на GitHub.

---

## 📌 Как это будет работать

Каждый раз, когда ты напишешь в чат:
> **«Сохрани версию»**, **«Закоммить 0.1v2»** или **«Запушь на гитхаб»**

Я автоматически:
1. Обновлю номер версии в [package.json](file:///c:/vibes/package.json) и [SettingsTab.tsx](file:///c:/vibes/src/components/tabs/SettingsTab.tsx).
2. Сформирую понятный коммит по стандарту (`feat: ...`, `fix: ...`, `refactor: ...`).
3. Создам Git-тег версии (например, `v0.1.2`).
4. Отправлю изменения на твой GitHub (`git push origin main --tags`).

---

## ⚡ Одноразовая настройка (занимает 1 минуту)

### Шаг 1. Создай репозиторий на GitHub
1. Зайди на [github.com/new](https://github.com/new).
2. Введи название репозитория: `vibes` (или любое другое).
3. Оставь его **Public** или **Private** (галочки README, .gitignore и License ставить **не нужно**).
4. Нажми **«Create repository»**.
5. Скопируй ссылку на репозиторий, например:
   `https://github.com/ТВОЙ_ЛОГИН/vibes.git`

### Шаг 2. Привяжи репозиторий (напиши мне или выполни команду)
Просто отправь мне ссылку в чат:
> *«Вот мой репозиторий: https://github.com/username/vibes.git, привяжи его»*

Либо выполни в консоли в папке `c:\vibes`:
```cmd
git remote add origin https://github.com/ТВОЙ_ЛОГИН/vibes.git
git branch -M main
git push -u origin main
```

## 🛠️ Готовый скрипт для ручного пуша в 1 клик

В проекте создан файл **`git_save.bat`**. 
Ты можешь просто запустить его двойным кликом в проводнике:
- Он запросит описание коммита;
- Автоматически добавит все файлы, создаст коммит и запушит в GitHub.
